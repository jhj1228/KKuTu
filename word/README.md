# update_db
**update_db**는 뜻을 DB에 자동으로 입력시켜주는 프로그램입니다.

---

## 사용 시 주의사항
- 본 프로그램은 신 표국대를 기반으로 한 자동화 프로그램입니다. 구 표국대를 사용하는 끄투에는 일부 호환되지 않을 수 있습니다.
- 본 프로그램은 node.js v24 환경을 기반으로 제작되었습니다. 구 버전의 node.js 환경에서는 테스트하지 않았습니다.
- g는 한국어기초사전, p는 표준국어대사전, u는 우리말샘을 의미합니다.
- 사용은 가능하지만, 사용 시 레전드끄투의 깃허브 링크를 반드시 표기하고 사용했음을 정확히 명시해주세요.
- pg 라이브러리가 필요합니다. `npm install pg`를 통해 pg 라이브러리를 다운로드해 주세요.
- 본 사용 방법은 Windows 기반으로 작성되었습니다. 리눅스는 모릅니다.

---

## 사용 방법
1. update_db 파일을 끄투 파일로 옮겨주세요.
2. update_db에서 DB_CONFIG에 본인의 DB 정보를 입력하고 저장하세요. 모른다면 sub/global.json에서 확인하세요.
3. cmd에서 update_db 파일이 있는 디렉토리로 이동해주세요.
4. `node .\update_db.js`를 입력해 js 파일을 실행해주세요.
