# word
**word**에는 끄투 DB를 직접 다루는 프로그램들입니다.

## 이용 시 주의사항
- **이 프로그램을 이용해도 되지만, 이용 시 이용했다는 흔적(깃허브 링크 및 저작권 고지 사이트 등)을 남겨주시기 바랍니다.**
- 본 프로그램들은 개조된 레전드끄투에 맞게 제작되었습니다. 일반 끄투에서 사용하기 위해서는 테이블 명을 kkutu_ko로 설정해주시기 바랍니다.
- pg 라이브러리가 필요합니다.
- node.js v24 환경에서 제작되었습니다. 구 버전에서 호환이 되지 않는다면 정성껏 개조해서 쓰시기 바랍니다.
- 본 프로그램들은 모두 정상적으로 테스트 완료되었습니다. 안심하고 사용하세요.

---

## update_db
**update_db**는 뜻을 DB에 자동으로 입력시켜주는 프로그램입니다.

---

## delete_theme
**delete_theme**은 특정 어인정 주제를 자동으로 삭제시켜주는 프로그램입니다.
